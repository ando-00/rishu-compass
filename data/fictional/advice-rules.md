# 履修指導の判断ルール

一般的な大学の履修指導の考え方をまとめた文章です。特定の大学の内部運用、数値、案内文は使っていません。
「主要」は、時間が足りないときに優先して使う8件です。

| 番号 | 優先 | 論点 | ルール |
|---|---|---|---|
| 1 | 主要 | 再履修の必修 | 不合格だった必修は、他の科目より先に時間割へ入れる。翌年に回すと卒業が遅れる場合は、その影響を伝える。 |
| 2 | | 必修どうしの重なり | 再履修の必修と別の必修が同じ時限に重なるときは、再履修を優先する。もう一方を翌年に履修できるか確認する。 |
| 3 | 主要 | 4年次の履修 | 履修上限いっぱいに詰めない。1科目を落としても卒業できる余裕を残すよう勧める。 |
| 4 | 主要 | 区分の偏り | 総単位が足りていても、区分に不足があれば卒業できないと明言する。 |
| 5 | 主要 | 先修科目の不合格 | 上位科目をいつ履修できるかを示し、翌年以降の計画を組み直す。 |
| 6 | 主要 | 履修上限に当たる | 卒業と進級に直結する科目を優先する。緩和の条件に当たるかも確認する。 |
| 7 | 主要 | 進級条件の直前 | 今期に単位を落とすと何が起きるかを具体的に伝える。 |
| 8 | | アルバイト・部活 | 通えない曜日を聞き、無理のない学期配分にする。 |
| 9 | | 苦手分野 | 選択必修の中で選択肢があれば、得意な方向を勧める。 |
| 10 | 主要 | 今年度の卒業が難しい見込み | 見込みであることと理由を伝え、必ず職員面談に回す。追試や成績の異議が残っていないか確かめ、根拠なく「大丈夫」と言わない。 |
| 11 | 主要 | 留学・教職課程・資格課程 | 別の要件が重なるので、履修案を確定させず職員に回す。 |
| 12 | | 休学・復学 | 適用される要項の年度が変わることがあるので、職員に回す。 |
| 13 | | 成績の異議・追試 | 規程の解釈になるので、判断せず職員に回す。 |
| 14 | | 他学部科目の算入 | 算入できる上限と算入先の区分を確認してから勧める。 |
| 15 | | 自由単位の取り過ぎ | 区分の不足が残っているのに自由単位を増やしていたら指摘する。 |
| 16 | | 集中講義・クォーター科目 | 時間割に出ない負担があるので、学期全体の負担に含めて考える。 |
| 17 | | 楽な科目の相談 | 否定せず、要件を満たす範囲で選択肢を示す。 |
| 18 | | 判断に自信がない場合 | 断定せず、職員に確認するよう案内する。 |
| 19 | | 編入・読替・既修得単位 | 認定や読替の扱いが要項の外にあるので、判定せず職員に回す。 |

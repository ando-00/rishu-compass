# 作業の一覧

夜間ループ（`.claude/skills/night-loop/SKILL.md`）が上から順に拾う。人が決めることと Claude が進めてよいことを分ける。

- 状態は「未着手」「作業中（日時）」「済（コミット）」「止めた（理由）」のどれかにする
- 作業の途中で解釈や方針の判断が要ると分かったら、その作業を止め、「人の判断」に質問と選択肢を移す。Claude は解釈の案を出さない
- 新しい作業を足すときは、判断が要らないことを確かめてから「判断不要」に入れる

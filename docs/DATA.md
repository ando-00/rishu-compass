## 正解ルールの作り方

正解ルールの内容は、作り手が要項を読んで決めました。ファイルへの清書は Claude が行いました。

- 作り手が決めたこと: 値、区分の分け方、根拠の文、どこを曖昧箇所とするか
- Claude が行ったこと: 質問と選択肢の作成、清書。解釈の案は出していません
- 例外として Claude が補ったこと: 曖昧箇所の質問文は設計書 v4 の表現から作りました。第6条の曖昧箇所の読み方は設計書 v4 の表現を作り手が選びました。第8条以降の根拠の文は、第2条〜第5条の方針に合わせて各条の本文を使いました

選択肢は Claude が作ったので、作り手の判断に影響した可能性があります。評価の結果はこの前提で読んでください。

### かもめ大学の正解ルール

さくら台大学と同じ方法で、作り手が手引きを読んで決め、Claude が清書しました。

- 作り手が決めたこと: 手引きの値、区分の分け方（コアと専攻を必修と選択に分ける）、どこを曖昧箇所とするか（10件）、未回答の間に止める範囲
- 仕様メモ v1 の仕込み4件（再履修、演習科目、履修中の必修、副専攻の中止）は、作り手が最初に2件の値を決めたあと、仕様との差を確認して4件とも曖昧箇所にしました
- 手引きは変えていません。両専攻の必修に載っている3科目の曖昧さは、Claude の変換で見つかったものです
- 例外として Claude が補ったこと: ルールと選択肢の `id`、質問文と選択肢の文面、根拠の文の選び方、未回答の間の仮の値
- 根拠の文について: 修得済みの科目の再履修は手引きに定めがないので、最も近い第5節「再履修科目は上限に含めません。」を根拠にしました

形式の制約で、次の点は手引きのとおりに表せていません。

| 箇所 | 扱い |
|---|---|
| 副専攻の範囲、両専攻の3科目、副専攻の中止、演習科目の範囲 | `patches` を `null` にした。回答しても判定に反映できず、関わる判定は止まったまま |
| 他学部の科目 | 科目データにないので区分の `groups` に書いていない。自由科目（副専攻あり）は科目群がなく、超過分だけが入る |

両専攻の3科目を未回答のまま止めるので、副専攻なしの学生の自由科目はすべて職員確認になります。卒業の判定は、確かな不足があれば「不足」、それ以外は職員確認です。「充足」と「見込み」にはなりません。

## 評価の結果

`evals/results/extract/` は、架空の要項を実際の Claude で変換した結果です。うまくいかなかった回も残します。ファイルの `commit` は実行したときのコミットです。プロンプトを正解ルールとの比較を見て直した回があるので、一致率は未知の要項での精度を示しません。

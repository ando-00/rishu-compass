## 正解ルールの作り方

正解ルールの内容は、作り手が要項を読んで決めました。ファイルへの清書は Claude が行いました。

- 作り手が決めたこと: 値、区分の分け方、根拠の文、どこを曖昧箇所とするか
- Claude が行ったこと: 質問と選択肢の作成、清書。解釈の案は出していません
- 例外として Claude が補ったこと: 曖昧箇所の質問文は設計書 v4 の表現から作りました。第6条の曖昧箇所の読み方は設計書 v4 の表現を作り手が選びました。第8条以降の根拠の文は、第2条〜第5条の方針に合わせて各条の本文を使いました

第13条の「不合格となった科目」に失格が含まれるかは、監査の第1回で疑問点として挙がり、作り手が曖昧箇所にすると決めました（2026-11-02）。質問文と選択肢の清書は Claude が行い、どの読み方が正しいかの案は出していません。今のルール変換はこの形（`retake`）を出力しないので、変換の結果との比較では見つからない項目として数えます。

選択肢は Claude が作ったので、作り手の判断に影響した可能性があります。評価の結果はこの前提で読んでください。

基礎教育と専門教育の「選択必修」「選択」の4区分の根拠の文は、第3条（超過の扱い）から第1条（区分ごとの最低単位）に変えました（2026-11-05、H26）。学生別の画面で、S0095 の基礎教育 選択必修の不足の根拠に第3条が出ていたためです。作り手は第1条と第3条の両方を選びましたが、根拠の文は要項のひと続きの抜き出しでないと検査で止まり、2つの条の間に表と第2条があるので、第1条だけに選び直しました。超過の扱いは `overflowTo` が持つので、判定は変わりません。

### かもめ大学の正解ルール

さくら台大学と同じ方法で、作り手が手引きを読んで決め、Claude が清書しました。

- 作り手が決めたこと: 手引きの値、区分の分け方（コアと専攻を必修と選択に分ける）、どこを曖昧箇所とするか（10件。のちに A1-16 で1件足して11件）、未回答の間に止める範囲
- 仕様メモ v1 の仕込み4件（再履修、演習科目、履修中の必修、副専攻の中止）は、作り手が最初に2件の値を決めたあと、仕様との差を確認して4件とも曖昧箇所にしました
- 手引きは変えていません。両専攻の必修に載っている3科目の曖昧さは、Claude の変換で見つかったものです
- 例外として Claude が補ったこと: ルールと選択肢の `id`、質問文と選択肢の文面、根拠の文の選び方、未回答の間の仮の値
- 卒業研究の着手の条件で「履修中でもよい」と読む場合に、判定の時点より後に履修した科目を認めるかは、監査の第1回の A1-16 で疑問点として挙がり、作り手が曖昧箇所にすると決めました（2026-11-02、`thesis-enrolled-timing`）。これで曖昧箇所は11件です。質問文と選択肢の清書は Claude が行い、どの読み方が正しいかの案は出していません
- 手引きの「7 時間割」は、作り手の決定で、履修案の検査の時限の重なりの根拠として示します（2026-11-02、`timetable`）。値は持たず、時限は科目データにあります。根拠の文は第7節の本文全体を Claude が選びました。これで手引きの全ての節が正解ルールのどこかの `clause` に載ります
- 根拠の文について: 修得済みの科目の再履修は手引きに定めがないので、最も近い第5節「再履修科目は上限に含めません。」を根拠にしました。2026-11-06 に作り手が、手引きは変えず、質問文に「手引きに定めがありません」と足すと決めました（H38）
- 手引きの「他学部の科目は、自由科目に上限なく算入できます。専攻科目には算入できません。」は、2026-11-06 に作り手が決め、自由科目の区分の根拠の文に足しました（H38）。文を足しただけで、科目データに他学部の科目がないので判定は変わりません。手引きの連続した部分しか根拠の文にできないので、副専攻ありの区分には間のコア科目の文も入っています。範囲の選び方は Claude が補いました

形式の制約で、次の点は手引きのとおりに表せていません。

| 箇所 | 扱い |
|---|---|
| 副専攻の範囲、両専攻の3科目、副専攻の中止、演習科目の範囲 | `patches` を `null` にした。回答しても判定に反映できず、関わる判定は止まったまま |
| 他学部の科目 | 科目データにないので区分の `groups` に書いていない。自由科目（副専攻あり）は科目群がなく、超過分だけが入る |

両専攻の3科目を未回答のまま止めるので、副専攻なしの学生の自由科目はすべて職員確認になります。卒業の判定は、確かな不足があれば「不足」、それ以外は職員確認です。「充足」と「見込み」にはなりません。

## 学生データの偏り

生成器で作るので、実際の大学にはない偏りがあります。提出までは直しません（H37）。直すと、全ての人数と評価の数字が変わるためです。

- かもめ大学は、専攻と年次を同じ通し番号から決めています。心理学専攻は1・3年次、社会学専攻は2・4年次だけで、4年次の心理学専攻はいません
- さくら台大学の2〜4年次は、225人のうち220人が前年度の GPA 3.0 以上です
- 2校とも、全員の現在の学期が後期です

## 評価の結果

`evals/results/extract/` は架空の要項を実際の Claude で変換した結果、`evals/results/advise/` は評価用の10名の履修案を実際の Claude で作った結果、`evals/results/score/` はその採点です。うまくいかなかった回も残します。ファイルの `commit` は実行したときのコミットです。プロンプトを正解ルールとの比較を見て直した回があるので、一致率は未知の要項での精度を示しません。

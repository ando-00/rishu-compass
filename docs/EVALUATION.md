# 評価

**架空の2校と、作り手が内容を決めた正解とテストによる評価です。実際の大学での精度を示すものではありません。** 10名で誤りが0件でも、統計的な保証にはなりません。

さくら台大学のプロンプトは、正解との比較を見て直しました。そのため、さくら台大学の一致率は未知の要項での精度を示しません。かもめ大学は正解に合わせた調整をしていません。

## 確かめ方

保存した変換の結果を、今のコードで検査し直せます。Claude を呼ばないので API キーは要りません。

```bash
npm run eval:recheck   # 全ての回の一致、最新の回の検出、根拠の文、全学生の判定の一致
npm run eval:score     # 履修案の検査の通過、未確定の表示、正解があれば危険な誤り
npm test               # 判定エンジンと API のテスト
```

## 分かったこと

**さくら台大学は、3回のうち1回が第6条の曖昧箇所を見逃しました。** 3回を統合したので残りました。1回だけの変換なら、見逃したまま確定で通っていた可能性があります。

**かもめ大学は、見逃しが多く残りました。** 正解の曖昧箇所10件のうち7件を検出できていません。演習科目の定義は、科目データの科目群「演習」が見えているので質問になりにくいと考えています。曖昧さの見つけ方を仕込みの一覧に合わせて直すと評価の意味がなくなるので、直していません。

**見逃した曖昧さは確定で通ります。** かもめ大学の全学生の判定1666件で、正解では職員確認なのに案では見込みになるものが48件ありました（読み方 `credit-basis=earned`）。この作品は、Claude が見逃した箇所では止まりません。解釈の正しさは職員の確認に依存します。

**かもめ大学の判定の一致は1252/1666です（未回答のとき）。** 差の多くは案のほうが止まる側で、割れた項目を要確認にしたためです。職員が認めたルールの分だけ、止まる範囲は減ります。

危険な誤りの定義は次の6つです。`evals/scoring.ts` で数えます。

- 不足があるのに足りていると示す
- 足りているのに不足と示す
- 今年度の卒業が難しい見込みなのに可能と示す
- 卒業できるのに延期見込みと示す
- 職員に回すべき学生や案を回さない
- 未確定のルールを確定として示す
